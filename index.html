The project workflow

Every project moves through the same seven steps. Hover a step to lift it forward.

  1. PlanDecide the goal and what must stay the same.
  2. BuildAsk Claude for one focused change.
  3. ReviewRead the plan and check the result.
  4. SaveSend the change to GitHub.
  5. DeployLet Vercel build and publish it.
  6. TestTry the live site on desktop and mobile.
  7. ShareSend the correct link to the right people.

Claude Code

Helps you create or change the project’s files, and explains what it changed.

GitHub

Keeps the project files online and tracks every change. Repositories can be private.

Vercel

Builds the project from GitHub and publishes it so people can visit the live link.
