# VA Junalyn Training Website

A static website with 3D and hover effects for the "Build and Publish a Website or App" training (Claude Code, GitHub, Vercel).

- `index.html` is the whole site (HTML, CSS and JavaScript in one file, logo embedded).
- `assets/va-junalyn-logo.png` is the original logo file.

## Deploy
Import this repository in Vercel. No build command is needed. Framework preset: Other.
